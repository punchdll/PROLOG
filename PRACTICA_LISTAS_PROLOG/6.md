# 1.8 Ejercicio 6: Obtener el último elemento
───────────────────────────────────────────

Crea el predicado `ultimo/2` que retorne el último elemento de una lista.  Consulta:
┌────

│ ?- ultimo([a,b,c,d], X).

└────

```prolog

ultimo([X | []], X).    %Cuando la lista solo tiene un elemento (Cabeza), lo unifica con U
                        %que es el ultimo elemento

ultimo([_ | COLA_A], U):- ultimo(COLA_A, U).    %Aqui no nos importa la cabeza solo pasamos la cola recursivamente hasta encontrar nuestro caso base

```

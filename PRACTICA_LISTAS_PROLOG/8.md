# 1.10 Ejercicio 8: Eliminar un elemento de una lista
───────────────────────────────────────────────────

Crea un predicado `eliminar/3` que elimine la primera aparición de un elemento en una lista.  Consulta:

┌────

│ ?- eliminar(c, [a,b,c,d,c], R).

└────

```prolog
eliminar(_, [], []). %al eliminar cualquier elemento de una lista vacia nos da la lista vacia como caso base cuando no encontramos el elemento

eliminar(Elemento, [Elemento | Cola], Cola). %si eliminamos la cabeza de una lista nos da solo la cola (sin el elemento a eliminar)

eliminar(Elemento, [Cabeza | Cola], [Cabeza | Resto]) :- Elemento \= Cabeza, eliminar(Elemento, Cola, Resto).%Si el elemento que estamos buscando no está en la cabeza, seguimos buscando en la cola recursivamente.
```

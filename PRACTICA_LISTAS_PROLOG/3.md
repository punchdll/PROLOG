# 1.5 Ejercicio 3: Calcular la longitud de una lista
──────────────────────────────────────────────────

Define un predicado `longitud/2` que devuelva la cantidad de elementos
de una lista.  Consulta:
┌────
│ ?- longitud([a,b,c,d], N).
└────

```prolog
longitud([], 0).                          
longitud([_ | Resto], N) :- longitud(Resto, N1), N is N1 + 1.
```

# 1.5 Ejercicio 3: Calcular la longitud de una lista
─────────────────────────────────────────────────


Define un predicado `longitud` que devuelva la cantidad de elementos de una lista.  Consulta:

┌────

│ ?- longitud([a,b,c,d], N).

└────

Tenemos un predicado unario que relaciona una lista vacia con una longitud de 0.

La siguiente regla desprecia la cabeza de la lista pero pasa el resto recursivamente hasta que cumple la condición del predicado. De ahi empieza a unificar el valor de N en cada llamada recursiva.


```prolog
longitud([], 0).                          

longitud([_ | Resto], N) :- longitud(Resto, N1), N is N1 + 1.
```

Ejemplo:

```prolog
?- longitud([a,b,c,d], N).
longitud([a | [b, c, d]], N) :- longitud([b, c, d], N1), N is N1 + 1.
longitud([b | [c, d]], N) :- longitud([c, d], N1), N is N1 + 1.
longitud([c | [d]], N) :- longitud([d], N1), N is N1 + 1.
longitud([d | []], N) :- longitud([], N1), N is N1 + 1.

longitud([], 0).

longitud([d | []], 1) :- longitud([], 0), N is 0 + 1.
longitud([c | [d]], 2) :- longitud([d], 1), N is 1 + 1.
longitud([b | [c, d]], 3) :- longitud([c, d], 2), N is 2 + 1.
longitud([a | [b, c, d]], 4) :- longitud([b, c, d], 3), N is 3 + 1.

N=4
```

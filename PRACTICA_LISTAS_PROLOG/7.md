#1.9 Ejercicio 7: Sumar los elementos de una lista numérica
──────────────────────────────────────────────────────────

Define un predicado `suma_lista/2` que calcule la suma de los
elementos de una lista de números.  Consulta:

┌────

│ ?- suma_lista([2,4,6,8], S).

└────

```prolog
suma_lista([], 0). %Definimos el caso base como la suma de una lista vacia que es 0.
suma_lista([CABEZA_A | COLA_A], Suma):- suma_lista(COLA_A, X), Suma is X + CABEZA_A.% A partir de ahi le vamos sumando cada cabeza de la lista para que lo unifique en suma.
```

Ejemplo:
```prolog
?- suma_lista([2,4,6,8], S).
suma_lista([2 | [4, 6, 8]], Suma):- suma_lista([4, 6, 8], X), Suma is X + 2.
suma_lista([4 | [6, 8]], Suma):- suma_lista([6, 8], X), Suma is X + 4.
suma_lista([6 | [8]], Suma):- suma_lista([8], X), Suma is X + 6.
suma_lista([8 | []], Suma):- suma_lista([], X), Suma is X + 8.

suma_lista([], 0)

suma_lista([8 | []], 8):- suma_lista([], 0), Suma is 0 + 8.
suma_lista([6 | [8]], 14):- suma_lista([8], 8), Suma is 8 + 6.
suma_lista([4 | [6, 8]], 18):- suma_lista([6, 8], 14), Suma is 14 + 4.
suma_lista([2 | [4, 6, 8]], 20):- suma_lista([4, 6, 8], 18), Suma is 18 + 2.

S=20
```
